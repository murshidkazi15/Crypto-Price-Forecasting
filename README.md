# 📈 Cryptocurrency Time-Series Price Forecasting

A Python project for modeling, decomposing, and forecasting cryptocurrency price movements using moving average indicators, trend analysis, and time-series evaluation metrics.

---

## 📌 Features

- **Historical Price Data Modeling:** Simulates 365 days of daily Bitcoin (BTC) & Ethereum (ETH) price histories.
- **Technical Indicator Computation:** Calculates 7-day and 30-day Simple Moving Averages (SMA) and 14-day annualized volatility.
- **Forecast Metric Evaluation:** Evaluates predictive accuracy using Root Mean Squared Error (RMSE) and Mean Absolute Percentage Error (MAPE).

---

## 🚀 Getting Started

### Installation & Run

```bash
git clone https://github.com/murshidkazi15/Crypto-Price-Forecasting.git
cd Crypto-Price-Forecasting
pip install -r requirements.txt
python forecast_model.py
```
